# Files that often come with tensor files

- Hex Viewer (.bin, .img or other binary files): Opens binary files of any size, with find, a data inspector and byte editing.
- Pickle Viewer (.pkl files): Opens Python pickle files without Python and never runs their code.
- HDF5 and NetCDF Explorer (.h5 or .nc files): Browses groups, attributes and values in HDF5 and NetCDF files and plots slices.

Each one is a separate free extension. Nothing installs on its own.
